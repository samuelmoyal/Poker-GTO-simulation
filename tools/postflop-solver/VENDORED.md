Upstream sources are unmodified. Local additions only:

- `.cargo/config.toml` — allows the `dangerous_implicit_autorefs` lint, which recent `rustc` denies by default (the 2023 code
  triggers it; no functional change), and builds for the host CPU (`target-cpu=native`, so binaries are machine-specific).
- `examples/turn_bench.rs`, `examples/flop_bench.rs` — solve-time benchmarks for turn and flop roots.
- `Cargo.lock` — generated by our builds.

Build notes: use `--no-default-features --features rayon` (the default `bincode` feature pins `2.0.0-rc.3`, which no longer
resolves to a compatible release; we do not need to save/load game trees). Our crates already depend on it that way.
